## 💡 Come Consultare e Scaricare i PDF

1. **Da Computer**:
   - Cliccando su **[Apri PDF]** o direttamente sul nome del file nella lista in alto, GitHub apre il lettore PDF integrato a schermo intero.
   - Per salvare il file sul computer, clicca sul pulsante **Download raw file** (o sul link **[Scarica]** nella tabella).
2. **Da Smartphone / Tablet**:
   - Clicca sul link **[Scarica]** corrispondente alla materia desiderata per salvare subito il PDF nel lettore del tuo dispositivo (es. Adobe Acrobat, Apple Books, Google Drive).
